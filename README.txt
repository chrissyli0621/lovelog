Lovelog v9.3 · ChatGPT + Claude 聊天记录本机整理

部署：和以前一样，在原来的 Netlify 项目里 "Already built it?" 上传这个 ZIP，不要新建项目（新网址看不到旧数据）。
更新后如果画面没变，关掉 App 再开一次（可能要开两次）。v8 沿用同一个本机数据库，已导入的对话、收藏、备注都会保留。
建议：部署后先到「设置 → 资料与备份」按一次「导出备份」。

========== v9.3 更新 ==========
修復：iPhone 主屏幕 App 頂端 / 底部留白（iOS 26 的已知問題，WebKit 把可視高度算短了一個狀態欄的高度）。
- 去掉了之前「自動偵測再猜」的補丁，它在 iOS 26 上會猜錯（頁頭頂到時間上就是它造成的）。現在只用系統給的安全區數值。
- 狀態欄改成不透明樣式，這樣底部不再留白，頂端是一條系統狀態欄。
- 這個樣式是「添加到主屏幕」那一刻存下的：要先刪掉主屏幕上舊的 Lovelog 圖標，用 Safari 重新打開網址，再添加一次。
- 設置 → 效能 → 頂部留白 仍然可以手動調：頁面頂端多出一塊空白選「去掉」，頁頭被時間蓋住選「加上」。
美化：統計、回收桶、導入記錄、跳過清單、找重複 這幾頁的頁頭和首頁、對話頁統一（小標籤 + 襯線標題 + 漸變分隔線）；統計的數字、小標題用襯線字；每月 token 圖最後一個日期不再和前一個重疊。

========== v9.2 更新 ==========
首页

  只会记录更新之后读过的对话，所以刚更新时这一块是空的，读几个对话就出现了。
- 空状态美化：那年今日没有记录、画廊没有图片、收藏还是空的时，都有各自的提示卡，不再是一块空白。
对话页
- 顶部统一风格：上方一行日期与星期，标题用衬线字，底下一条渐变分隔线。
搜索速度已在 10 万多条消息的库上测过，不需要改动。

========== v9.1 更新 ==========
修复：iPhone 上页面最上面（页头和侧栏）多出一大块空白。
- 原因：页面已经在状态栏下面开始了，却又重复加了一次状态栏的高度。

========== v9 更新（在 v8.2 基础上，数据完全通用） ==========
1. 新「首页」（照夏至首页的做法，内容全部用你自己的聊天记录生成）：
   - 大号日期 + 两张斜叠的照片（那天聊天里的图；没有就用随机的，同一天固定同两张）。
   - 前 14 天小日历：有聊天的日子带点，点一天看那天聊了什么；‹ › 每次翻 14 天，「选日期…」可以直接跳到任何一天。
   - 「那年今日」：往年同一天的聊天，做成斜挂回形针的小卡片（il y a 2 ans · 2024）；这一天没有，就找往年同一日的前几个月。
   - 存档卡片：隨手一句（从旧聊天里抽一句，中文竖排，点一下换，↗ 回到原处）、画廊（聊天里的图，点一下换）、
     数字（天数、对话数、最忙的一天）、收藏（对话 / 消息 / 书签数，点开看全部）、最近的书签、随机翻一段。
   - 我的夹：分类和标签变成小卡片，点一下筛选。
   - 回到首页：点页头的「Lovelog」，或者没打开任何对话时就是首页。
2. 气泡样式（设置 → 气泡与玻璃）：都有 / 只有我 / 只有 AI / 都没有。
   「只有我」：我说的话有气泡，AI 的话直接排在页面上，像一篇文章。
3. 新增 Cormorant Garamond 字体（日期、年份数字）；离线时自动用 Georgia。

========== v8.2 更新（在 v8.1 基础上） ==========
1. 模糊模式改成和夏至一样：气泡整个糊 7px，点一下清楚，再点一下糊回去。不再糊列表标题，也没有眼睛按钮了。
2. 本机储存改成「分块」：对话每 25 个存一块，改动（删除、还原、导入少量）时只重写有变的那几块。
   - 以前整个资料库是一整块存的：对话很多时，每删一个都要整包重写，会卡；
     而且在电脑版 Chrome 一整块超过约 128MB 就存不进去（会提示本机储存失败）。分块以后没有这个上限。
   - 第一次改动时会自动把旧格式升级成新格式（对话多的话会花几秒，顶部会显示「正在升级本机储存格式」）。
   - 注意：升级以后，更旧的版本（v8.1 及以前）读不到这份资料。升级前先「导出备份」一次最保险。
3. 新增「流畅模式」（设置 → 效能）：关掉气泡、卡片、侧边栏背后的磨砂玻璃，捲动更顺。
   - 设置里有「测速」按钮，会在你的设备上实际比一次「玻璃效果」和「流畅模式」，并告诉你建议开不开。
   - 模糊模式开着的时候，气泡的磨砂玻璃会自动省掉（气泡本来就糊了）。

========== v8.1 更新（在 v8 基础上） ==========
1. 导入后会给一份报告：这次文件里一共读到几个对话、ChatGPT / Claude 各几个、其中几个含多个版本（会出现 ‹1/2›）。
   - 某个平台显示「含多个版本的 0 个」，说明这份导出文件里没有版本信息，所以不会出现 ‹1/2›。
   - 「空对话」：导出里有这个对话，但里面没有任何可显示的消息，所以没有放进列表。
   - 「文件内重复」：同一个文件里同一个对话出现了两次，只留一个。
   - 完整清单在 设置 → 资料与备份 → 导入记录 → 每个压缩包下的「跳过清单」。
   - 想看以前导入的压缩包的报告：把它再导入一次，不会重复添加，只会补上报告。
2. 备份文件现在也包含回收桶（30 天内删掉的对话），还原时一起带回来；合并还原不会重复。

========== v8 更新 ==========
1. 删除与回收桶
   - 侧栏「选择」→ 勾几个（或「全选」当前筛选结果）→「删除」。对话右上「⋯ → 删除这个对话」也可以。
   - 删掉的先进回收桶，30 天后自动清掉；刚删完底部会出现「撤销」。
   - 设置 → 资料与备份 → 回收桶：可以单个还原、全部还原、单个永久删除、清空（清空才会真的腾出空间）。
   - 设置里有「删除全部对话」（也是先进回收桶）。
2. 按压缩包管理：设置 → 资料与备份 → 导入记录
   - 从 v8 起，每次导入都会记下文件名和时间；每条可以「只看这批」或「删除这批」。
   - 对话也出现在别的压缩包里时会提醒你，可以选只删「只在这批」的。
   - v8 以前导入的显示成「更早导入（来源不明）」。把原来的压缩包再导入一次就会补上来源，不会重复添加。
   - 对话标题下面会写「来自：xxx.zip」。
3. 同一段对话不再变成两个：v8 会记住平台给每段对话的 ID。之后导入新的导出包时，
   之前导过、后来又多聊了几句或改了标题的对话，会直接换成新版本（收藏、备注保留）。
4. 找重复的对话：设置 → 资料与备份 → 找重复的对话。同平台、建立时间完全一样的会列出来，
   一键「每组保留最完整的，其余移到回收桶」，收藏/备注/标签会合并过去。
5. 收藏整个对话：对话右上角的 ☆。侧栏「★ 收藏」= 收藏的对话 + 有收藏消息的对话，收藏的对话排前面。
6. 置顶：「⋯ → 置顶」，固定在列表最上面。
7. 标签：「⋯ → 标签」，自己取名字，一个对话可以有好几个；侧栏项目旁边会多出「#标签」可以点来筛选。
   和导入时带来的「项目」分开，互不影响。选择模式里可以一次给很多个对话加/去标签。
8. 书签：消息下面「⋯ → 在这里加书签」，可以取个名字。标题旁出现书签按钮，点开就能跳过去。
9. 阅读位置：长对话看到一半离开，下次打开会回到那里（底部提示「从头看」可以回到开头）。
10. 那年今日：首页（没打开对话时）会列出往年今天聊过的对话；往年没有就列前几个月的今天。还有「随机翻一段」。
11. 一起导出：选择模式 →「导出」→ Markdown / TXT / 长图。可以合成一个文件，或每个对话一个文件打包成 ZIP。
    长图会用你上次在「截长图」里调的样式。
12. 更强的筛选：搜索框右边的按钮 → 日期范围、只搜我说的 / 只搜 AI 说的、只看有图片 / 有 artifact 的对话。
    开着的筛选会显示在侧栏，点 ✕ 取消。
13. 模糊模式：设置 → 隐私。照夏至的做法：开了以后气泡整个糊起来，点一下看清楚，再点一下又糊回去。
14. 顺一点：侧栏列表改成往下滑才继续画（以前一次画四千多行），搜索分批进行，打字时不会卡住。

========== 第二轮新增 ==========
A. 标题：恢复成原来那种粗而紧凑的 Georgia 衬线；标题里的 *星号* 会显示成斜体。
B. 复制气泡内容：每个气泡下面有一个很淡的小图标（AI 和你自己的都有），点一下复制文字；
   电脑上鼠标移到那则消息才会变清楚。「⋯」里还有「复制全部」（连思考过程、artifact 一起）。
C. 回溯 / 重新生成的版本切换：有多个版本的消息会在时间旁出现 ‹ 1/2 ›，点箭头来回看。
   - ChatGPT 导出：以前所有分支会被混成一长串，现在只显示「目前这条」，其他版本收进 ‹ n/N ›。
     编辑过的提问（连同后面的整段对话）也算一个版本，切过去后面的消息会一起换。
   - 夏至格式（JSON 里的消息带 all / vi）也读得懂；「匯出到夏至」会把版本一起带回去。
   - Claude 的导出如果带有分支信息（parent_message_uuid）也会读；如果没有，就只能看到当时选中的那一版。
   - 你选了哪一版会被记住，下次打开还在。已经导入过的旧对话，把原来的 ZIP 再导入一次就会「更新」成有版本的样子（不会重复，收藏也保留）。
D. 收藏与备注：每则消息的 ☆ 收藏、「⋯ → 写备注」；侧栏「★ 收藏」按钮只看有收藏的对话。
E. 日期筛选：侧栏的「全部日期」可选某个月；统计页点日历格子可跳到那一天。
F. 统计页：每月 token 曲线（点曲线看那个月）、日历热力图、最长对话排行。
G. 导出：对话右上「⋯」→ Markdown / TXT / 长图 / 匯出到夏至。
   长图：见上面「截长图」。太长会自动分成几张。
H. 备份与还原：设置 → 资料与备份。备份是一个 .json（含对话、图片、收藏备注、版本选择、配色）。
   还原：把备份文件直接用「＋」导入即可，可选「合并」或「覆盖」。
I. 图片：Claude 的导出 ZIP 里本来就没有图片文件（只有文件名），所以显示成占位框。
   点占位框可以补上那张图；也可以在设置里「批量补图」，一次选很多张，按文件名自动配对。
J. 「进阶 → 检查资料结构」改名为「诊断（出问题才用）」：平时完全不用管，只有某种内容没显示出来时，
   选原始 ZIP，它会列出字段名称和类型（不含聊天文字），复制给我就能对症处理。
